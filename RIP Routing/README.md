# 🌐 RIP Routing Network Topology

## 📌 Project Overview

This project demonstrates **RIP (Routing Information Protocol)** configured using **Cisco Packet Tracer**.

The topology consists of multiple routers, switches, and end devices connected through different networks. RIP is used as a dynamic routing protocol to exchange routing information between routers and enable communication between different networks.

- 🖥️ Cisco Packet Tracer

- 📡 Dynamic Routing
- 🔀 Cisco Routers
- 🔗 Cisco 2960 Switches
- 💻 End Devices
- 🌍 IP Addressing
- 🔗 Router-to-Router Connectivity

## 🏗️ Network Topology

The topology contains multiple interconnected routers with different LAN networks.

Each router is connected to switches and end devices, while router-to-router links are used to exchange routing information using RIP.

## ⚙️ Configuration

### 🔹 RIP

**RIP stands for Routing Information Protocol.**

RIP is a dynamic routing protocol that allows routers to automatically exchange routing information and learn routes to remote networks.

### 🔹 RIP Version

The routers are configured with RIP to advertise their directly connected networks.

RIP uses **hop count** as its metric to determine the best path.

The maximum usable hop count is **15**, while **16 hops is considered unreachable**.

### 🔹 Dynamic Routing

RIP automatically:

- 🔄 Exchanges routing information
- 🌐 Learns remote networks
- 🧭 Selects the best available route
- 🔁 Updates routing information when network changes occur
