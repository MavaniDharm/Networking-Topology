# 🌐 Static Routing Network Topology

## 📌 Project Overview

This project demonstrates **Static Routing** configured using **Cisco Packet Tracer**.

The topology consists of multiple routers, switches, and end devices connected through different networks. Static routes are manually configured on the routers to establish communication between remote networks.

## 🛠️ Technologies Used

- 🖥️ Cisco Packet Tracer
- 🌐 Static Routing
- 📡 Cisco Routers
- 🔀 Cisco 2960 Switches
- 💻 End Devices
- 🌍 IP Addressing
- 🔗 Router-to-Router Connectivity

## 🏗️ Network Topology

The topology contains multiple interconnected routers with different LAN networks.

Each router is connected to one or more switches and end devices, while router-to-router links are used for communication between different networks.

## ⚙️ Configuration

### 🔹 Static Routing

**Static Routing** is a routing method where routes are manually configured by the network administrator.

Static routes are added on each router to specify:

- 📍 Destination Network
- 🚪 Next-Hop Address
- 🔗 Exit Interface

### 🔹 Router Configuration

Each router is configured with the required static routes so that devices from different networks can communicate with each other.

Unlike dynamic routing protocols, static routing does not automatically learn or update routes.
