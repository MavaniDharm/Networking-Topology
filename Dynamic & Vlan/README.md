# 🌐 DHCP & VLAN Network Topology

## 📌 Project Overview

This project demonstrates a **DHCP & VLAN network topology** created using **Cisco Packet Tracer**.

The topology includes multiple VLANs, switches, PCs, and a router configured to provide network connectivity and DHCP services.

## 🛠️ Technologies Used

- 🖥️ Cisco Packet Tracer
- 🌐 VLAN
- 📡 DHCP
- 🔀 Cisco 2960 Switches
- 📍 Router-on-a-Stick
- 💻 Multiple End Devices

## ⚙️ Configuration

### 🔹 VLAN Configuration
Multiple VLANs are created to logically separate different network segments.

### 🔹 DHCP Configuration
DHCP is configured to automatically assign IP addresses to devices in different VLANs.

### 🔹 Inter-VLAN Routing
The router is configured for **Inter-VLAN Routing using Router-on-a-Stick**, allowing communication between different VLANs.

### 🔹 Switch Configuration
Multiple Cisco 2960 switches are connected using trunk links to carry traffic between VLANs.
