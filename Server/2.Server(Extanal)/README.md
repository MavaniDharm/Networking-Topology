# 🌐 External Server Network Topology

## 📌 Project Overview

This project demonstrates an **External Server Network Topology** created using **Cisco Packet Tracer**.

The topology consists of a router, Cisco 2960 switch, an external server, and multiple PCs connected within the same network.

The server is configured as an **External Server** to provide network services to connected devices.

## 🛠️ Technologies Used

- 🖥️ Cisco Packet Tracer
- 🌐 External Server
- 📡 Router
- 🔀 Cisco 2960 Switch
- 💻 PCs
- 🌍 IP Addressing
- 🔗 LAN Connectivity

## 🏗️ Network Topology

The network uses the **192.168.1.0/24** network.

| Device | IP Address |
|--------|------------|
| Router | 192.168.1.254 |
| External Server | 192.168.1.1 |
| PC0 | 192.168.1.3 |
| PC1 | 192.168.1.4 |

All devices are connected through a Cisco 2960 switch.

## ⚙️ Configuration

### 🔹 External Server

The server is configured with a static IP address:

**IP Address:** `192.168.1.1`

The server can be used to provide different network services to client devices depending on the configuration.

### 🔹 Router

The router interface is configured with:

**IP Address:** `192.168.1.254`

It acts as the default gateway for the network.

### 🔹 Client PCs

The PCs are configured with static IP addresses:

- PC0 → `192.168.1.3`
- PC1 → `192.168.1.4`
